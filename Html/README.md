# Maa Sarada storefront design

Open `index.html` directly, or run `python3 -m http.server 8080 --directory Html` from the repository root and visit http://localhost:8080.

Buildless HTML, CSS and JavaScript. No framework, CDN, font service or runtime dependency. All images are stored locally. Responsive layouts include mobile navigation, manually controlled hero slides, product search, saved products, a persistent local shopping bag, a countdown and accessible newsletter feedback. The carousel does not auto-advance.

This is a frontend design preview, not a live commerce integration. Prices, ratings, statistics and testimonials are sample content. Product illustrations are CSS placeholders rather than exact SKU photographs. The app badges honestly indicate an upcoming app. Newsletter submission does not collect data; checkout, customer accounts and order tracking need backend integration. Replace the example email and showroom details before launch. Review and replace all policy and marketing claims with verified business content.
